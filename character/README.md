# Put your character pictures here

Drop 7 pictures in this folder with **exactly** these names:

| File | Pose |
|---|---|
| `idle.png` | standing, hands clasped, smiling |
| `wave.png` | waving hello |
| `run.png` | running to the right |
| `run_happy.png` | running happily holding a water bottle |
| `drink.png` | drinking from a water bottle |
| `angry.png` | hands on hips, frowning |
| `pout.png` | sad pout, chin on hands (upper body) |

- `.png`, `.jpg` or `.webp` all work.
- A **solid bright green background** is removed automatically. Transparent PNGs work too.
- Any picture you leave out is replaced by Drippy, the built-in water drop.
- These pictures are **not** uploaded to GitHub (see `.gitignore`), so your face stays on your computer.
